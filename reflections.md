# STAR Reflections

## 1. Reflection on coding in Markdown

**Situation:**  
I had never used Markdown before this assignment. My CV and project descriptions were always in Word or PDF.

**Task:**  
Create a professional portfolio using only Markdown, including my CV and project details.

**Action:**  
- Learned basic Markdown syntax (headings, lists, links, images) from GitHub's guide.  
- Converted my existing CV into `cv.md`.  
- Used GitHub's preview feature to check formatting.  
- Added screenshots using `![alt](image-link)`.

**Result:**  
My portfolio is clean, readable, and version-controlled. I can now write documentation quickly. This will help me in open-source projects.

## 2. Reflection on mock interview video

**Situation:**  
I needed to record a mock interview and reflect on my performance.

**Task:**  
Answer typical IT graduate interview questions on video and upload it to my portfolio.

**Action:**  
- Prepared answers for "Tell me about yourself" and "Describe a challenging project."  
- Recorded using my phone in a quiet room.  
- Watched the recording to identify areas for improvement (eye contact, filler words).  
- Uploaded the video to YouTube as "Unlisted" and embedded it in my README.

**Result:**  
I feel more confident for real interviews. I learned to structure my answers using STAR and to speak clearly.

## 3. Reflection on using GitHub Pages

**Situation:**  
My portfolio had to be live on the web, not just a repository.

**Task:**  
Deploy my Markdown portfolio using GitHub Pages.

**Action:**  
- Went to Settings → Pages in my repository.  
- Set source to `main` branch and root folder.  
- Waited 2 minutes for deployment.  
- Tested the live link on different devices.

**Result:**  
My portfolio is now accessible at `https://entle-myezo.github.io/EntleMyezoPortfolio/`. I understand how static site hosting works.
